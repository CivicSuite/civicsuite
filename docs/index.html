CivicSuite

An open-source municipal product suite that runs on the city's own hardware.

CivicSuite is a sovereignly deployable, local-first product program for municipal operations. The suite already has one shipping product, one productizing second-product candidate, a shared platform package, and a broad set of real foundations that are not yet end-to-end products.

  • Local firstNo cloud requirement, no telemetry, no per-seat pricing.
  • Product depth over repo countThe roadmap treats “all repos have releases” and “a city can run on this” as different milestones.
  • Continuity is gatedPlatform expansion does not continue until continuity and succession work is in place.

What happens next

Phase 0 is active. Continuity is now an explicit gate. As of 2026-04-29, the CivicSuite GitHub org still has a single visible member/owner (scottconverse), so the roadmap does not treat platform expansion as complete or unblocked yet.

  • Land the second-org-owner and succession deliverables.
  • Finish the shared auth/RBAC extraction proof and rollout playbook.
  • Extract the next civiccore capabilities that unblock civicclerk.
  • Drive civicclerk to true second-product status with a real identity and deployment story.

Why this framing changed

The suite now documents three different truths separately: what is already shipping, what is in active productization, and what is still foundation work. That distinction matters because a city evaluates deployability, recoverability, identity, security, and operations, not just repo count.

The roadmap is designed to move the suite from a broad portfolio of promising repos into a deployable municipal starter set, then into a city-scale product platform.

Architecture

Every module inherits the same deliberately boring stack: FastAPI, PostgreSQL 17 with pgvector, Redis 7.2, Celery, Ollama, and React behind nginx. Modules depend on civiccore; civiccore never depends on modules. Cities run the stack on their own hardware.

The first deployable target is not “all 26 modules at once.” It is a coherent starter set with shared identity, audit, retention, export, and upgrade behavior.
