CivicSuite

An open-source municipal product suite that runs on the city's own hardware.

CivicSuite is a sovereignly deployable, local-first product program for municipal operations. Public shipping, product-ready, and v1.0 maturity claims are frozen while the suite re-earns release status through stronger recovery gates.

  • Local firstNo cloud requirement, no telemetry, no per-seat pricing.
  • Product depth over repo countThe roadmap treats "all repos have releases" and "a city can run on this" as different milestones.
  • Continuity is gatedPlatform expansion does not continue until continuity and succession work is in place.

What happens next

The active work is city-core nontechnical installability. The profile has current Linux and Windows matching-host lifecycle evidence, first-run browser QA, green PR CI, and audit-full evidence in the active run record. The honest state is beta-ready truth-reconciled.

  • Keep macOS explicitly beta/archive/readiness only.
  • Keep CivicAccess and Tier 2 modules outside this run.
  • Use live regenerated artifact hashes, source pins, and attestations as the trust path.
  • Keep Linux Guided Setup tied to Docker's signed package repositories where supported.
  • Record real terminal and screenshot evidence for every integration claim.
  • Advance later modules one at a time only after city-core closes with evidence.

Why this framing changed

The suite now documents release labels as provisional until they are re-earned. That distinction matters because a city evaluates deployability, recoverability, identity, security, and operations, not just repo count or tag count.

The roadmap is designed to move the suite from a broad portfolio of promising repos into a proven municipal starter set, then into a city-scale product platform.

Architecture

Every module inherits the same deliberately boring stack: FastAPI, PostgreSQL 17 with pgvector, Redis 7.2, Celery, Ollama, and React behind nginx. Modules depend on civiccore; civiccore never depends on modules. Cities run the stack on their own hardware.

The first deployable target is not "all 27 product modules at once." It is a coherent starter set with shared identity, audit, retention, export, and upgrade behavior.
