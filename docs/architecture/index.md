# Architecture Decision Records

Cross-module architectural decisions are recorded here as ADRs. Each ADR
is a single markdown file named `ADR-NNNN-short-title.md`.

ADRs scoped to a single module live in that module's repo, not here. Use
this folder for decisions that affect two or more modules, the platform
contract, or the suite as a whole.
