## [0.4.0] - 2026-06-28

City-core hardening: closes probe gaps #2 (authz), #3 (audit), and #4 (backup/restore), and makes the shared CivicCore PostgreSQL the default review store.

### Added

- Added a trusted-write guard: persistent writes (`POST /api/v1/civicaccess/review`, `POST /api/v1/civicaccess/reviews/{id}/records-export`) now require the `CIVICACCESS_TRUSTED_WRITE_TOKEN` server secret, sent as the `X-CivicAccess-Write-Token` header. Missing/invalid token returns 403; unconfigured guard fails closed with 503. (Probe gap #2.)
- Added `POST /api/v1/civicaccess/analyze`: a stateless, public, no-persistence accessibility check. The public `/civicaccess` surface now uses it, so public users can no longer write city records.
- Added a persisted `audit_events` table and module audit events on writes/exports: `review.create` is committed atomically in the same transaction as the review record; `review.records_export` emits a standalone audit row on export. (Probe gap #3.)
- Added durability proofs: a Postgres reconnect round-trip for the default store (review + audit survive a fresh engine) and a SQLite dev-fallback backup/restore round-trip. (Probe gap #4.)
- Added a mandatory PostgreSQL release gate: `verify-release.sh` and CI require `CIVICACCESS_POSTGRES_TEST_URL` so PostgreSQL persistence coverage cannot be skipped, plus `tests/test_postgres_persistence.py`.

**Notable findings**:

- CivicAccess does NOT include LLM calls, outbound network calls, or live AI services — all accessibility checks and plain-language rewrites are deterministic, preserving reproducibility and offline operation.
- Schema version name follows Windows Local convention: civicaccess-windows-local-state-v1, matching CivicCore pattern in supervisor.
- Persistence uses a shared PostgreSQL by default (DATABASE_URL from supervisor converted sync psycopg2) but gracefully falls back to local SQLite dev DB if no shared database is configured.
- Write authorization is stateless via header token (not session/JWT) and uses constant-time HMAC comparison, avoiding timing attacks.
- The staff UI page never embeds the write token in HTML; operator must paste it into a field and it stays in sessionStorage only during that browser session.
- Public /civicaccess route is stateless (uses /analyze endpoint) so public users cannot persist records; only authenticated staff via /civicaccess/staff with token can save.
- The module is declared optional in the installer (selectable=true, required=false) and is 'wired but not yet offered' in services.py (OPTIONAL_MODULE_IMPORTS), meaning health failures do not degrade overall system.
- The repo's v1.0.0 release was published in error and corrected to v0.2.0; honest phase classification remains 'standalone readiness candidate' and 'not yet shipping'.
