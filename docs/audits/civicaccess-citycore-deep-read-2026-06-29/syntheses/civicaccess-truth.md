**What Civicaccess Is**:

CivicAccess v0.4.0 (C:/dev/Codex/civicaccess) is a deterministic, no-LLM FastAPI module for accessibility review, plain-language rewrites, multilingual sample variants, ADA Title II review plans, tagged-PDF expectations, accessible-form planning, publishing-workflow checks, and records-ready export checklists.

CODE: 8 Python modules in civicaccess/ totaling ~1900 lines. __init__.py:3 declares __version__="0.4.0". main.py:1-495 has the FastAPI app, 17 route handlers, the write-token guard (main.py:381-398), and DB-URL selection (main.py:401-428). access_review.py:1-350 contains deterministic accessibility findings (review_accessibility, access_review.py:256-320) plus a SQLAlchemy AccessibilityReviewRepository (access_review.py:98-253) backed by a civicaccess Postgres schema (CREATE SCHEMA IF NOT EXISTS civicaccess at access_review.py:108) holding three tables: accessibility_review_records, audit_events, schema_migrations (access_review.py:54-86). Schema version is the literal "civicaccess-windows-local-state-v1" at access_review.py:52 — matches the Windows-Local convention. Helpers: plain_language.py, multilingual.py, exports.py, workflows.py (accessible-form/publishing-workflow/ADA-Title-II/tagged-PDF planners), public_ui.py (renders /civicaccess and /civicaccess/staff HTML), db_admin.py (CLI shipped as civicaccess-db-status console script).

DEPENDENCIES: pyproject.toml pins civiccore v1.2.0 release wheel + fastapi + sqlalchemy + uvicorn + pydantic. No LLM SDK, no outbound HTTP, no Ollama. Health endpoint reports CIVICCORE_VERSION (main.py:108).

VERSION: 0.4.0 released 2026-06-28 per CHANGELOG.md. The prior NEEDS-WORK demoted v0.2.0 (2026-05-23) was reversed by the 2026-06-29 depth re-probe (docs/audits/civicaccess-citycore-reprobe-2026-06-29.md). source_commit pin is 7b24516fd89584d84c12394b9385eddd1e8c6897.

PERSISTENCE STRATEGY: shared CivicCore Postgres preferred — main.py:416-428 reads DATABASE_URL the supervisor injects, falls back to CIVICACCESS_REVIEW_DB_URL override, falls back to local SQLite at CIVICACCESS_DATA_DIR/civicaccess-reviews.db. _sync_database_url (main.py:401-413) rewrites asyncpg -> psycopg2 cleanly using sqlalchemy.engine.make_url so credentials with marker substrings survive.
