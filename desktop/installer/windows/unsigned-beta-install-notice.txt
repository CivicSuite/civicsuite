CivicSuite Windows Beta Install Notice

CivicSuite is beta-level open-source municipal software. This Windows installer is not code-signed yet, so Windows may show a Microsoft Defender SmartScreen warning before the installer opens.

If SmartScreen appears:

1. Confirm the installer came from an official CivicSuite release or a trusted CivicSuite test build.
2. Choose "More info".
3. Confirm the app name is CivicSuite.
4. Choose "Run anyway" to continue.

This warning is expected for unsigned beta software. It does not mean CivicSuite is malware. It means Windows does not yet have a paid code-signing certificate reputation for this installer.

The Windows local install path is designed for non-technical city staff:

- No Docker requirement.
- No WSL requirement.
- No terminal requirement for normal use.
- CivicCore is installed as the required shared platform.
- CivicRecords AI, CivicClerk, and CivicCode are installed as the city-core module set.
- Data, logs, backups, and model files stay on the city's machine unless staff explicitly configure an external connector.
- The installer creates a standard Windows uninstall entry so CivicSuite can be removed from Windows Settings.
- The CivicSuite app also exposes repair, backup, restore, and uninstall guidance from System Health.

Before continuing, choose the install location, first city profile, first admin user, model download location, and backup location carefully. CivicSuite stores official drafts, audit trails, municipal records workflow data, and local model artifacts in those locations.
